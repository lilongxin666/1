# NIR / 化学计量学常用科研提示词

下面这些提示词可以直接复制到 Codex / Agent 中使用。核心原则是：**先限定数据边界和验证框架，再让模型写代码或分析结果。**

## 1. 数据检查

```text
请检查这个近红外数据集的结构、样本数、类别分布、波数范围、缺失值、重复样本和异常光谱。
不要开始训练模型。先输出数据质量报告，并指出任何可能造成数据泄漏或样本分组错误的问题。
```

## 2. 建立严格的分类基线

```text
请建立一个可重复的 NIR 三分类基线。
要求：
1. 固定随机种子；
2. 特征选择和调参不得使用 hold-out test 标签；
3. 使用嵌套交叉验证；
4. 先比较 Raw、SG、SNV、MSC 和一阶导数；
5. 主模型使用 SVM；
6. 输出 Accuracy、Balanced Accuracy、Macro-F1、MCC、混淆矩阵；
7. 报告 outer folds 均值±标准差；
8. 保存每个 outer fold 的参数和结果 CSV。
```

## 3. UVE / MC-UVE + SVM

```text
请在每个 outer training fold 内执行 UVE/MC-UVE 特征筛选，再在 inner CV 内调整阈值和 SVM 超参数。
outer test 只能用于最终预测。
输出：每折特征数、选中特征、性能、特征频率和总运行时间。
最后比较全光谱 SVM 与 UVE/MC-UVE-SVM，并分析是否真正提高泛化能力和稳定性。
```

## 4. DBO / PSO 特征优化

```text
请把 NIR 特征选择定义为二进制/混合优化问题，并设计一个适用于 DBO/PSO 的 fitness。
目标不仅是提高分类性能，还要约束特征数量并惩罚重复运行中的不稳定性。
先说明编码方式、fitness、边界、种群规模、迭代次数、停止条件和随机种子，再写代码。
所有优化必须在 inner CV 中完成，不得查看 outer test 标签。
```

## 5. 比较两个特征选择方法

```text
请公平比较方法 A 与方法 B。
必须使用完全相同的数据划分、预处理候选、SVM 搜索空间和评估指标。
每个随机方法至少重复 20 次。
除了均值性能，还比较：
- 特征数量
- 特征选择频率
- Jaccard/Kuncheva 稳定性
- outer fold 波动
- 运行时间
最后判断差异来自更好的搜索、更多特征，还是偶然性。
```

## 6. 批次稳定性 / 抗干扰

```text
请把问题定义为“模型在批次/样品状态变化下的稳定性”，而不是普通随机划分准确率。
按照批次或干扰条件进行 grouped split / leave-one-batch-out 验证。
比较全光谱、普通特征选择和稳定性特征选择。
重点输出跨批次性能下降、特征重合率和预测偏移，并分析哪些谱区更稳定。
```

## 7. 仪器迁移 / 模型转移

```text
请把源仪器和目标仪器严格分开，先建立未校正基线，再比较校正/迁移方法。
不要随机混合两个仪器的数据后再划分训练测试。
输出：迁移前后 RMSE/Accuracy、bias、光谱差异、关键波段变化和样本需求量。
```

## 8. Nature 风格科研图

```text
请根据当前实验结果设计一张投稿级多面板图。
要求：每个 panel 回答一个明确问题；避免重复信息；坐标、字体、线宽、图例和 panel 标签统一；不使用装饰性渐变和无意义阴影；最终同时输出矢量 PDF/SVG 和 600 dpi PNG/TIFF。
先给出 a/b/c/... 每个 panel 的科学问题和数据来源，再绘图。
```

## 9. 结果段落

```text
根据这些图表写 Results。
只陈述结果，不在每一句中加入原因推测。
按照“总体趋势 → 关键数值 → 方法间差异 → 稳定性/统计证据 → 小结”组织。
所有数字必须来自提供的表格或代码输出，不得补造。
```

## 10. Discussion

```text
根据 Results、关键谱带和真实参考文献写 Discussion。
必须回答：
1. 为什么该方法有效；
2. 相比全光谱和传统特征选择真正解决了什么；
3. 稳定性是否支持方法优势；
4. 关键谱带是否有合理光谱学解释；
5. 哪些结果可能只来自数据集特性；
6. 研究局限和下一步是什么。
不要只重复 Results。
```

## 11. 文献拆解

```text
请把这些近红外/化学计量学论文按统一模板拆解：研究问题、样本量、仪器、光谱范围、预处理、数据划分、特征选择、模型、指标、关键图表、主要结果、创新点、局限，以及哪些设计可以借鉴到我的研究。
所有文献信息必须可追溯到原文。
```

## 12. 投稿前自查

```text
请以严格审稿人视角审查当前 NIR 论文。
优先检查：数据泄漏、交叉验证设计、特征选择是否嵌套、重复运行是否充分、统计检验是否合适、比较是否公平、图表是否支持结论、谱带归属是否有文献依据、创新点是否只是算法叠加。
把问题分为 Major / Minor，并给出可执行修改建议。
```
