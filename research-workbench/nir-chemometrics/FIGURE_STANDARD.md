# NIR 论文作图规范

目标：图首先服务于科学问题，其次才是视觉风格。默认面向 Nature / Nature Communications / 高水平化学计量学期刊常见要求。

## 1. 总体原则

- 每个 panel 只回答一个主要问题。
- 多面板图统一字体、字号、线宽、刻度、图例风格和 panel 标签。
- 不使用 3D 柱状图、装饰性渐变、阴影立体效果或无统计含义的填充。
- 避免图例遮挡数据。
- 优先矢量输出：PDF / SVG；同时保留 600 dpi PNG/TIFF。
- 所有结果图必须能由脚本重新生成。

## 2. 光谱图

### 原始光谱

建议：

- x 轴使用 `Wavenumber (cm⁻¹)` 或 `Wavelength (nm)`，不要混用。
- 如果当前数据范围为约 4000–9200 cm⁻¹，可统一显示 4000–9200，并以 1000 cm⁻¹ 为主刻度间隔。
- 同一类别可以使用较低 alpha 展示单条光谱，并叠加类别均值；是否显示置信带取决于图的科学目的。
- 如果只是展示三类原始光谱，不要额外添加没有定义的阴影带。
- 光谱线过多时，避免 100% 不透明导致整图变成色块。

### 预处理比较

不要把所有预处理塞进一张图。优先选择：

- Raw vs 最终预处理；或
- 2×2 小面板展示关键处理。

## 3. 特征选择图

推荐三种表达：

### A. 选中特征叠加在光谱上

- 原始/平均光谱为浅色背景。
- 选中特征用垂直短线、marker 或轻量高亮标记。
- 不建议几十个宽色块遮住光谱。

### B. 重复运行选择频率

- x：波数
- y：Selection frequency
- 明确频率定义，例如 `selected runs / total runs`。
- 阈值线必须在图注解释，不能只画一条红虚线不说明含义。
- y 轴上限由真实结果决定，不为了“看起来接近”手动压缩。

### C. 特征稳定性

可展示：

- outer fold × wavenumber heatmap
- Jaccard / Kuncheva distribution
- 每折特征数量箱线图/散点图

## 4. 模型性能图

### 分类

推荐：

- confusion matrix
- outer-fold metric distribution
- repeated-run violin/box + raw points
- Accuracy / Balanced Accuracy / Macro-F1 / MCC 的紧凑比较

不要只给单个 accuracy 柱状图。

### 回归

推荐：

- predicted vs reference
- residual plot
- outer-fold RMSE / MAE distribution

predicted-vs-reference 图需要：

- 1:1 line
- 明确 calibration / validation / test
- 样本点不要被大 marker 完全覆盖

## 5. 多面板图推荐结构

对于“特征选择方法 A vs 方法 B”的论文，可采用：

```text
(a) 原始三类光谱
(b) 方法 A 的选中特征分布
(c) 方法 A 的重复运行选择频率
(d) 方法 B 的选中特征分布
(e) 方法 B 的重复运行选择频率
(f) 两方法的性能/稳定性比较
```

或者左右对称：

```text
左：Method A  [a 原始/输入] [b 选中特征] [c 频率]
右：Method B  [d 原始/输入] [e 选中特征] [f 频率]
```

如果左右两组使用同一原始光谱，可考虑只保留一次原始光谱，避免重复信息；除非对称布局本身是比较逻辑的一部分。

## 6. Panel 标签

- 使用 `(a)`, `(b)`, `(c)` 或 `a`, `b`, `c`，全文统一。
- panel 标签放在每个 axes 左上角外侧或稳定位置。
- 不让标签与 y 轴刻度重叠。

## 7. 字体与尺寸

脚本中不要依赖某台电脑才有的特殊字体。优先使用通用无衬线字体。

建议：

- 轴标题略大于刻度字号
- panel 标签使用半粗体
- 图例字号略小于轴标题
- 最终缩放到论文栏宽后仍可阅读

## 8. 颜色

- 同一类别在全文保持相同颜色语义。
- 同一方法在不同图中保持相同颜色语义。
- 不只依靠红/绿区分类别；考虑色盲可读性。
- 黑白打印时，线型、marker 或轮廓仍应可区分。

## 9. 误差表达

所有误差条、阴影或箱体必须明确代表什么：

- SD
- SE
- 95% CI
- outer-fold distribution
- repeated-run distribution

不能写一个“±”而不说明来源。

## 10. 图注必须说明

至少包含：

- 样本或重复次数
- 指标定义
- 阴影/误差条含义
- 阈值线含义
- 统计检验（如有）
- 关键缩写

## 11. 出图前审计

生成最终图后检查：

- 是否有文字被裁切？
- 图例是否遮挡？
- panel 是否对齐？
- x/y 轴范围是否一致且有比较意义？
- 是否存在人为固定频率上限而与数据不符？
- 是否存在重复的 0.3、0.5 等刻度标签？
- 虚线是否与阈值位置严格一致？
- 最终 PDF 中字体是否正常嵌入？

## 12. 推荐与 `nature-figure` 配合方式

绘图前先给 Agent：

```text
先不要画图。根据我的论文问题和已有 CSV，先列出每个 panel 回答的科学问题、所用数据列、统计量和坐标范围。确认逻辑后再使用 nature-figure 生成脚本和最终图片，并执行碰撞/对齐检查。
```
